🧩 Untangle Survival — Pisahkan Semua Garis

Untangle Survival adalah game puzzle berbasis web bertema dark mode neon di mana pemain harus menggeser titik-titik simpul (nodes) hingga tidak ada lagi garis yang saling bersilangan atau menimpa sebelum batas waktu habis.

✨ Fitur Utama

Mode Survival Tanpa Batas (Endless): Dimulai dari Level 1 dengan 5 titik dan terus meningkat kerumitannya tanpa batas maksimal.

Batas Waktu Progresif (3–5 Menit):

Level 1 – 3 (Mudah): 3 menit (03:00)

Level 4 – 7 (Menengah): 4 menit (04:00)

Level 8+ (Susah): 5 menit (05:00)

Bonus Waktu & Sistem Skor: Menyelesaikan level memberikan skor tambahan berdasarkan tingkat kesulitan dan sisa waktu, serta bonus +10 detik untuk level berikutnya.

Titik Terkunci (Locked / Anchor Nodes): Mulai Level 5 muncul titik bergembok emas yang tidak bisa digeser sebagai tantangan ekstra.

Indikator Visual Real-Time:

Garis menyala merah saat masih berpotongan dan berubah menjadi hijau saat bebas.

Titik yang masih memiliki garis menimpa berpendar merah tipis agar cepat dikenali.

Kontrol Lengkap & Responsif: Mendukung layar sentuh (HP/tablet) maupun mouse, dilengkapi tombol Undo, Acak Ulang, Pause (Jeda), serta efek suara sintetis bawaan (Tone.js).

Penyimpanan Rekor Lokal: Rekor level tertinggi tersimpan otomatis di browser menggunakan localStorage.

🎮 Cara Bermain

Tekan tombol MULAI MAIN di layar utama.

Tarik dan geser titik-titik biru di layar agar posisi garis tidak saling menimpa.

Pisahkan seluruh garis hingga semua berubah menjadi hijau sebelum waktu hitung mundur habis.

Gunakan tombol Undo untuk mengembalikan langkah terakhir atau Acak Ulang jika posisi titik terasa buntu.

🛠️ Teknologi yang Digunakan

HTML5 Canvas API — Rendering graf planar, animasi partikel, dan deteksi perpotongan segmen garis (Counter-Clockwise / CCW Intersection).

Tailwind CSS (CDN) — Antarmuka responsif dan gaya visual modern.

Tone.js — Efek suara sintetis interaktif tanpa memerlukan file audio eksternal.

Lucide Icons — Ikon antarmuka yang bersih dan ringan.
